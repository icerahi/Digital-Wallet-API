# Team Roles and Responsibilities

In accordance with Agile methodology and the final project requirements, our team of students is structured with distinct roles to ensure separation of concerns and efficient delivery of the Digital Wallet API.

## Team Structure

### 1. Imran - Team Member (Backend Developer)
**Responsibilities:**
- Designing the MongoDB database schemas (Mongoose models).
- Implementing the RESTful web service endpoints (Node.js, Express, TypeScript).
- Ensuring architectural compliance with REST Level 3 (HATEOAS, Statelessness).
- Integrating the external RapidAPI service.
- Setting up the Swagger documentation.
- Managing GitHub branches and merges.

### 2. Emmanuel - Team Member (QA Specialist)
**Responsibilities:**
- Writing End-to-End automated API tests using BDD (Cucumber.js).
- Running Postman collections and Swagger tests to verify API endpoints.
- Verifying the implementation of Functional and Non-Functional Requirements.
- Presenting the automated API test results during the final evaluation.

### 3. Augustine - Product Owner & Scrum Master
**Responsibilities:**
- Gathering requirements and drafting `REQUIREMENTS.md` (Product Backlog).
- Managing the Trello board to track Sprints.
- Managing task priorities and Agile workflows.
- Defining User Stories and Acceptance Criteria.
- Ensuring the team follows Agile best practices and meets deadlines.

*(Note: If the team is smaller (e.g., 2 students), roles can be combined such as Developer + QA).*
